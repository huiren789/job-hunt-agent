# 追踪表模板（13 列）

可用 Excel / 飞书表格 / Notion 数据库实现。列名如下，顺序即列序 A–M：

| 列 | 字段 | 说明 |
|---|---|---|
| A | 岗位 | 岗位名称 |
| B | 平台 | 来源平台/渠道 |
| C | 投递日期 | YYYY-MM-DD |
| D | 用的话术 | 话术模板编号或简述 |
| E | 状态 | 见下方下拉 |
| F | 下次跟进日 | 提醒日期 |
| G | 对方原话 | 逐字保留，不改写 |
| H | 证据截图 | 本地路径（不要传公开仓库） |
| I | 反馈归因 | 8 类短名，见 docs/04 |
| J | 待补技能 | 从真反馈提炼 |
| K | 追问状态 | 见下方下拉 |
| L | 邮件message_id | 去重 + 线程匹配 |
| M | 面试信息 | 时间/地点/轮次 |

## 下拉合法值

**E 状态**：待投 / 已投 / 已读/已联系 / 面试邀约 / 面试完成 / offer / 被拒 / 无回音 / 暂停

**I 反馈归因**（8 类短名）：技术栈不符 / 经验不足 / 专业口径 / 到岗时间 / 薪资 / 沟通表达 / 岗位关闭 / 无反馈

**K 追问状态**：未追 / 已起草 / 待确认 / 已发 / 已回 / 结束

## 纪律

- 客套拒信不写 G/I/J（见 docs/04），只把状态改成被拒即可。
- 一条消息只对应一行；同一公司不同岗是不同行。
- 用户明确"不投"的岗也要记一行（状态=暂停，备注原因），防止重复推荐。
