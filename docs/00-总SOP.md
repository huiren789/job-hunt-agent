# 00 · 端到端总 SOP

这是整套系统的主索引。所有细节文件在 `docs/`，本文件把流程串成一条闭环。

## 十步闭环

```
① 筛岗（定时任务/手动检索）
② 三关筛选 + 去重（见 01）
③ 定制话术 + 简历（见 03）
④ 投递（本人确认后提交）
⑤ 反馈检测：邮箱闭环 + 招聘站本地只读脚本（见 automation/）
⑥ 五类判断（见 02）
⑦ 过了→提醒本人；拒了→高置信度下自动追问；想聊→自动跟进（见 02/03）
⑧ 拒后回理由→只存真样本（见 04）
⑨ 按需生成改进计划（见 05）
⑩ 不符原因回流，校准筛选规则（见 06）
```

## 执行前先读

- 基本盘：自己的年级/专业/可用时间/技术证据，逐条写清（这决定筛选和话术）。
- 硬约束：所有读写只在工作区内；不编造岗位/薪资/结果；含糊归"其他"；关键提交前停下让人确认。

## 当前能力边界（诚实标注）

- 招聘站本地检测：只读抓投递状态；遇到平台的极验/滑块等反自动化验证一律跳过、不硬闯。
- 自动发信：仅高置信度场景 + 用户显式预授权 + 可一句话撤回；其余发送需人工确认。
- 改进计划：没有真实样本时明确拒绝生成，绝不编造。
