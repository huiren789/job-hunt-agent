# 03 · 话术原则

## 去 AI 味 5 原则

1. **一封只问一件事**：不要"顺便问问A、B、C"，收件人只会回最容易的那个。
2. **砍套话**：删掉"您好感谢您百忙之中审阅"这类堆叠敬语；开头直接说你是谁、为什么写。
3. **带一个具体细节**：用你真实做过的一个点（项目数字、技术细节），让对方知道你不是群发。
4. **给低成本选项**：把回复成本降到"回一句有没有这个口子就行"或"A/B/C 选一个"。
5. **不卑不亢**：不自我贬低，也不施压；陈述事实与意图即可。

## 话术模板（占位符按实际情况替换）

### A 类 · 面试相关（永不自动发，本人确认）
- **A1 确认面试时间**：`您好，我是{姓名}，收到{公司}的面试邀约。想确认一下{日期}的面试时间/形式是否仍有效？`
- **A2 问清本轮内容**：`您好，想请教一下本轮面试主要考察哪些方向，方便我针对性准备。`

### B 类 · 拒后追问（高置信度下可预授权自动发）
- **B1 三选一问原因（推荐）**：
  ```
  您好，感谢{公司}的反馈。想请教一下，这次未通过主要是因为：
  A 技术栈/项目经验  B 专业或年级口径  C 到岗时间
  回一个字母就行，对我帮助很大。
  ```
  要点：给选项=降低回复成本；不解释、不辩护。

- **B2 问"下次最该补什么"**：`您好，方便的话想请教：以我目前的情况，最该优先补的一件事是什么？`

### C 类 · 想进一步聊（高置信度下可预授权自动发）
- **C1 顺势问改进意见**：在回应对方邀约后，附一句"也方便说说您看重的能力是什么吗"，保留真实署名。

### 自荐 / 冷邮件（新渠道主动联系）
结构：一句身份（年级+专业）→ 一句你做过的具体事（带数字/链接）→ 一句低成本请求。
```
您好，我是{年级} {专业}在读{姓名}。
我自己做过{项目}，{一个具体数字/验证结果}，代码在{链接}。
想问一句：贵司招不招{目标方向}的实习？不方便的话回我一句就行。
```

## 落款约定
- 追问类话术可不落款（逻辑链条已清楚）；
- 正式沟通保留署名；
- 同一套系统内保持一致，别一封有一封没有。
