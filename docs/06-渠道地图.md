# 06 · 渠道地图

不要只盯一两个招聘平台。按类型铺开渠道，能给同一套筛选规则更多候选。

## 渠道类型与适配

| 类型 | 例子 | 特点 | 用法 |
|---|---|---|---|
| 综合招聘平台 | 主流 App/网页 | 量大，但鱼龙混杂、卡年级多 | 主战场，配合三关筛 |
| 垂直实习平台 | 实习类网站 | 岗位更聚焦在校生 | 重点刷"不限年级 / 可远程" |
| 低年级专属通道 | 大厂青云/顶尖实习计划 | 明确欢迎低年级，但多为算法/研究岗 | 适合有论文/竞赛/开源硬证据的人 |
| 企业官网直投 | 公司招聘页 | 绕开平台海投，HR 邮箱可自荐 | 中小厂最值得试，主动邮件 |
| 地方龙头 / 产业生态 | 龙头企业及其供应链中小厂 | 龙头门槛高，生态里的小厂更缺人 | 找业务对口的小厂，而非龙头本身 |
| 国家级 / 高校就业平台 | 官方就业网、校内就业网 | 免费、安全，岗位多面向毕业生 | 低年级要筛；返乡/地方项目可关注 |
| 远程社区 | 远程工作社区 | 灵活，但偏自由职业/兼职 | 低频筛，挑能写进简历、有人带的 |
| 非代码 AI 岗 | AI产品 / AIGC运营 / Prompt工程 | 不要求精通算法，增长快 | 非科班背景反而适配，避开算法红海 |

## 排查一个渠道时问什么

1. 年级门槛：低年级能不能投？
2. 时间口径：每周几天、持续多久、能否远程？
3. 技术栈：和已有作品重不重合？
4. 有人带吗：是真实项目还是打杂？
5. 入口：官网直投 / 邮箱 / 平台，是否还在招？

## 渠道盘点的沉淀方式

每看一个岗，记：公司、要求要点、结论（可试/排除）、不符原因。
原因分类建议：年级卡 / 时间冲突 / 专业卡 / 经验门槛 / 方向不符 / 地域风险。
统计原因分布 → 反推筛选规则该先卡哪一道（经验：年级卡通常是最大淘汰原因，应前置）。
