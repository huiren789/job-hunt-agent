# 01 · 筛选规则

## 一、三关硬门槛（不满足不投）

1. **技术活**：产出代码 / 工具 / 可展示作品。纯销售、客服、标注流水线不算。
2. **有人带**：明确导师带、真实项目、有反馈。只丢任务没人带的不算。
3. **时间兼容**：与你可投入的时间对得上（学期内 / 假期 / 远程）。

三关是硬门槛，不是加分项。任何一关不满足就跳过，别用"其他条件好"来补偿。

## 二、硬门槛之前先卡两道（省时间的经验）

- **年级门槛**：很多实习明卡"某届在读 / 应届"。低年级（如大一大二）投这些必被筛，先看清楚再决定。
- **时间口径**：把"每周几天 × 持续多久 × 能否远程"写成固定句式，逐岗比对；要求全职而你在校的，直接跳过或先问能否调整。

## 三、一票否决

- 收费、押金、扣押证件、先交钱培训。
- 无薪 / 薪资明显不覆盖基本成本（除非明确以学习为目的且你能接受）。
- 销售伪装成"运营 / 管培"。
- 资质不清、岗位描述含糊、疑似虚假招聘。

## 四、加分项

- 主力技术栈与你已有项目重合（能直接展示作品）。
- 中小厂 / 初创，能接触真实项目、决策链短。
- 远程或时间灵活、明确可转正、有实习证明。
- 业务方向与你的专业背景形成交叉优势（而非硬转行）。

## 五、去重

- 建"已投 + 已判不符"清单，投前查。
- 同一公司不同岗算不同条目，但备注历史结论（例如曾被拒及原因）。
- 用户明确"不投"的公司/岗，写进排除清单，任何自动化都不得再推。

## 六、"特别好的岗位"判据（用于是否放宽地域/家庭约束）

把判据显式写下来，不要临场拍脑袋。常见维度：
钱明显高于基准 / 门槛你恰好够 / 生活质量好 / 可逆性强 / 需求大 / 城市本身想要。
是否放宽，由用户自己定；系统只摊开选项，不替用户决定。
